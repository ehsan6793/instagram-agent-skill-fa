# ig-human-fa

دو ابزار توی همین پوشه هست و هر دو واقعاً اجرا می‌شن. ازشون استفاده کن؛ چشمی قضاوت نکن.

```bash
python3 humanize.py draft.txt --report            # تمیزش کن، نشون بده چی عوض شد
python3 humanize.py draft.txt --spoken --report   # + کتابی -> محاوره‌ای
python3 detect.py draft.txt                       # امتیاز بده، شش چک
python3 detect.py draft.txt --register written    # متنِ بلند/نوشتاری: چکِ لحن حذف می‌شه
python3 detect.py before.txt after.txt            # اثبات کن چقدر فرق کرد
```

هر دو `slop.json` رو می‌خونن: بیش از ۱۲۰ واژه و عبارتِ کلیشه‌ایِ فارسی با جایگزینِ ساده، ۱۶ کلاسِ کاراکترِ نامرئی، ۱۰ جایگزینیِ تایپوگرافی، ۷۸ جفتِ کتابی→محاوره‌ای و ۱۸ ساختارِ ماشینی. بلوکِ `instagram` فقط واژگانِ کپشن و وویس‌اوره. قراره ویرایش بشه: اگه کاربر کلمه‌ای رو همیشه می‌گه و لغت‌نامه حذفش می‌کنه، از فایل درش بیار.

روی ویندوز اگه فارسیِ ترمینال وارونه بود `--visual` بزن (نیاز به `pip install arabic-reshaper python-bidi`).

## چرا این برای فارسی فرق داره (و چرا نباید از نسخه‌ی انگلیسی استفاده کنی)

اسکیلِ انگلیسی هر کاراکترِ U+200C (نیم‌فاصله) و U+200D رو پاک می‌کنه. توی فارسی **نیم‌فاصله جزوِ املاست**: «می‌روم»، «کتاب‌ها»، «خانه‌ی». پاک‌کردنش متن رو خراب می‌کنه («میروم»، «کتابها»). ZWJ هم توی ایموجی‌های ترکیبی لازمه. این نسخه:

- نیم‌فاصله بین دو حرف رو **نگه می‌داره**؛ نیم‌فاصله‌ی تکراری یا ولگرد (آخر کلمه، کنارِ فاصله) رو حذف می‌کنه.
- ZWJ فقط بین ایموجی می‌مونه؛ LRM/RLM فقط روی خطی که هم فارسی داره هم لاتین.
- هر چیزِ دیگه‌ی نامرئی (ZWSP، BOM، soft hyphen، bidi override، tag characterها) حذف می‌شه.
- ي/ك عربی → ی/ک، رقمِ عربی → فارسی، کشیده حذف.

## چیزهایی که خودکار درست می‌شن

**۱. کاراکترهای نامرئی** (بالا).

**۲. تایپوگرافی.** خط‌تیره‌ی بلند → «،»، گیومه‌ی فرنگی → «»، سه‌نقطه‌ی یونیکد → ...، بولت → خط‌تیره. خط‌تیره‌ی بلند مهم‌ترینه: بعدش علامتِ دوبل و نقطه‌ی یتیم هم تمیز می‌شه.

**۳. فرهنگ‌لغتِ کلیشه.** «در دنیای پرشتابِ امروز»، «شایان ذکر است»، «بدون شک»، «نقش کلیدی ایفا می‌کند»، «بی‌نظیر»، «بهینه‌سازی»، به‌علاوه‌ی بلوکِ اینستاگرام: «دوستان عزیز»، «لایک و فالو فراموش نشه»، «تا انتهای ویدیو با ما همراه باشید»، «نظرتون چیه». هر کدوم یا ساده می‌شه یا حذف.

**۴. محاوره‌ای‌سازی (`--spoken`، اختیاری).** می‌خواهم→می‌خوام، می‌توانید→می‌تونین، را→رو، است→ـه، اگر→اگه، بسیار→خیلی، جهت→برای، لذا→برای همین. **تقریبیه**؛ همیشه نتیجه رو بخون. لهجه‌ی خاص (شیرازی، اصفهانی، تهرانیِ خیلی خودمونی) رو نمی‌شناسه: اگه کاربر لهجه‌ی مشخص داره، از `voice.md` برو و دستی تنظیم کن.

## چیزهایی که خودکار درست **نمی‌شن**

ساختارهای ماشینی پرچم می‌شن، بازنویسی نمی‌شن، چون عوض‌کردنِ شکلِ جمله قضاوت می‌خواد:

- «این فقط X نیست، بلکه Y» و «نه تنها X، بلکه Y»
- سه‌تاییِ «الف، ب و ج»
- خطِ سوالیِ تک‌کلمه‌ای: «نتیجه؟»
- مقدمه‌ی ویدیو: «توی این ویدیو می‌خوام نشونتون بدم»
- «بیایید نگاهی بیندازیم / بپردازیم»، «موارد زیر»، «در راستای»
- لیستِ ایموجی‌دار، دیوارِ هشتگ (بیش از ۵، سقفِ اینستاگرام)
- طعمه‌ی رفلکسی: «کامنت بذارید»، «لایک و فالو»، «فراموش نکنید»
- **لحنِ کتابی** (چکِ REGISTER، پایین)

اینا کارِ توئه. هر خطِ پرچم‌خورده رو دستی بازنویسی کن، معنا رو نگه دار، بعد `detect.py` رو دوباره بزن. این بخش امتیاز رو از REVIEW به PASS می‌رسونه و اسکریپت نمی‌تونه انجامش بده.

## شش چک

`detect.py` شش سیگنال رو ۰ تا ۱۰۰ می‌ده، بالاتر یعنی انسانی‌تر:

| چک | چی می‌سنجه | ماشینی چه شکلیه |
| --- | --- | --- |
| BURSTINESS | تنوعِ طولِ جمله | همه‌ی جمله‌ها هم‌اندازه |
| SPECIFICITY | عدد، اسم، @هندل، «نقل‌قول» در هر ۱۰۰ کلمه (فارسی حرفِ بزرگ نداره، پس اسمِ خاص از فهرستِ نام‌ها و لاتین می‌آد) | اسمِ انتزاعی، بدونِ عدد |
| SLOP DENSITY | کلیشه در هر ۱۰۰ کلمه | واژگانِ آماده |
| FINGERPRINT | نامرئی، خط‌تیره‌ی بلند، گیومه‌ی فرنگی، ي/ك عربی در هر ۱۰۰۰ نویسه | تایپوگرافیِ بی‌نقص |
| VOICE | اول/دوم‌شخص و ساختارهای ماشینی (فارسی ضمیر رو می‌اندازه، پس مقیاس از طریقِ فعل‌ها هم می‌شمره) | «موارد زیر»، افشای صحنه‌ای |
| REGISTER | کتابی در برابر محاوره‌ای | «می‌باشد»، «جهت»، «لذا»، «همچنین» |

**REGISTER مهم‌ترین نشونه‌ی فارسیِ ماشینیه.** مدل‌ها پیش‌فرض کتابی می‌نویسن؛ آدم جلوی دوربین محاوره‌ای حرف می‌زنه. برای ریل، کامنت، دایرکت و استوری (پیش‌فرض) محاوره‌ای می‌خوایم. برای پستِ بلندِ نوشتاری با `--register written` این چک حذف می‌شه.

وزنِ حکم: میانگین ۶۰٪ و **ضعیف‌ترین چک** ۴۰٪، چون یه سیگنال کافیه. PASS یعنی کلِ ≥ ۷۰ و هیچ چکی زیر ۵۵ نباشه.

## صادق بگو

این‌ها شش heuristic محلی‌ان که روی چیزهایی ساخته شدن که تشخیص‌دهنده‌های عمومی و گوشِ خواننده بهشون حساسن. همه‌چیز روی دستگاه اجرا می‌شه و چیزی آپلود نمی‌شه. **GPTZero، Originality، Copyleaks، Winston یا Turnitin نیستن**، به API هیچ‌کدوم وصل نیستن و نمی‌تونن حکمشون رو تضمین کنن؛ و اون ابزارها فارسی رو معمولاً ضعیف‌تر از انگلیسی می‌فهمن. **وزن‌ها و آستانه‌ها روی داده‌ی فارسی کالیبره نشدن** (روی چند نمونه‌ی دستی تفاوتِ متنِ ماشینی و انسانی رو نشون می‌ده، نه بیشتر). ادعای بزرگ‌تر از این به جای کاربر نکن و هیچ‌وقت نگو متنش «غیرقابل‌تشخیص» شده.

## ترتیب کار

1. `humanize.py draft.txt -o clean.txt --report` (برای متنِ گفتاری `--spoken` هم)
2. پرچم‌های ساختاری رو بخون. اون خط‌ها رو خودت بازنویسی کن.
3. `detect.py draft.txt clean.txt` برای نشون‌دادنِ قبل و بعد.
4. اگه حکم PASS نیست، ضعیف‌ترین چکی که خروجی اسم برده رو درست کن و دوباره برو. دو دور عادیه. پنج دور یعنی پیش‌نویس با فرمول نوشته شده؛ راهش یه پیش‌نویسِ دیگه‌ست، نه پاس‌های بیشتر.
5. متنِ تمیز و امتیاز رو با هم به کاربر نشون بده. هیچ‌وقت فقط امتیاز.
