# ig-viral-fa

اسکیلِ تحقیق. بقیه‌ی بسته می‌نویسن؛ این یکی می‌ره و نگاه می‌کنه. ماهی یه بار اجراش کن، نه روزی. فرمول‌ها یه فصل دووم می‌آرن.

یه ابزار توی همین پوشه هست و اجرا می‌شه:

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

(ابزار برای نام‌گذاریِ فرمول از `../ig-reel-fa/hooks.json` و برای امتیازِ هوک از `../ig-reel-fa/hookscore.py` استفاده می‌کنه؛ پس هر دو پوشه باید کنارِ هم نصب باشن.)

## ایده‌ای که این کار رو ارزشمند می‌کنه

**بازدیدِ خام شاهد نیست.** پیجی با دو میلیون فالوور که ۴۰۰ هزار بازدید گرفته یه سه‌شنبه‌ی آروم داشته. پیجی با چهار هزار فالوور که ۴۰۰ هزار گرفته یه چیزی پیدا کرده، و اون چیز قابل‌کپیه.

پس همه‌چیز اینجا روی **ضریبِ outlier** رتبه می‌گیره: بازدید ÷ median اخیرِ خودِ همون پیج. بالای ۳× سیگنال. زیر ۱٫۵× روزِ عادیِ اون پیجه و هیچی یاد نمی‌ده، هر قدر عدد بزرگ باشه.

پیج‌ها رو **حدوداً تا ۱۰ برابرِ سایزِ خودِ کاربر** جمع کن. فرمولی که توی ۲ میلیون فالوور جواب می‌ده، اغلب به‌خاطر همون ۲ میلیون فالوور جواب می‌ده.

## قدمِ ۱: پیج‌ها رو انتخاب کن

از کاربر ۶ تا ۱۲ پیج بخواه یا پیشنهاد بده و تأیید بگیر:

- **۴ مستقیم** - همون حوزه، همون پیشنهاد، کمی جلوتر.
- **۴ هم‌جوار** - حوزه‌ی دیگه، همون مخاطب. فرمت‌ها قبل از اینکه کسی توی حوزه‌ی خودت داشته باشه از اینجا قرض گرفته می‌شن.
- **۲ تا ۴ خیلی بزرگ** - فقط برای فرمت، نه برای ریتم یا لحن.

از کاربر بخواه **Saved collection** خودش رو هم باز کنه. سریع‌ترین و مرتبط‌ترین مجموعه‌ست و از قبل با سلیقه‌ی خودش فیلتر شده.

حواست به **زبان** باشه: اگه حوزه‌ی کاربر فارسیه، پیج‌های فارسی‌زبان رو جمع کن. فرمتِ پیج‌های انگلیسی رو می‌شه قرض گرفت، ولی هوکِ اونا رو نمی‌شه ترجمه کرد و انتظارِ همون نتیجه داشت؛ فرهنگ (طنز، ضرب‌المثل، خطاب، پول) فرق می‌کنه.

## قدمِ ۲: برو و نگاه کن

از هر ابزارِ مرورگری که این نشست واقعاً داره استفاده کن: مرورگرِ داخلِ برنامه، افزونه‌ی متصل به کرومِ خودِ کاربر، یا computer use. API‌ای نیست و لازم هم نیست، چون حجمش اونقدر کمه که بشه خوندش.

**قاعده‌هایی که چانه‌زنی‌بردار نیستن:**

- **هیچ‌وقت از طرفِ کاربر وارد اینستاگرام نشو و هیچ‌وقت رمز نخواه.** اگه صفحه ورود می‌خواد، کاربر همونیه که قبلاً واردِ حسابشه. مرورگرِ اون رو با حضورِ خودش برون، یا ازش بخواه paste کنه.
- **این خوندنه، نه scraping.** ده پیج، دوازده ریل از هر کدوم، با سرعتِ آدم. جمع‌آوریِ خودکار با حجمِ بالا شرایطِ استفاده‌ی اینستاگرام رو نقض می‌کنه و حساب رو محدود می‌کنه. خزنده نساز، از سرویسِ scraping استفاده نکن، و توی پس‌زمینه لوپش نکن.
- **فرمول رو کپی کن، ویدیو رو نه.** شکلِ هوک، ساختار، طول، الگوی برش‌ها. نه اسکریپتشون، نه صداشون، نه ادیتشون. هر سطرِ swipe file رو به پیجی که ازش اومده نسبت بده.

**برای هر ریل با کلماتِ خودِ سازنده ثبت کن:**

| فیلد | توضیح |
| --- | --- |
| account | هندل |
| followers | از پروفایل (هر شکلی: `48K`، `۴۸ هزار`، `۴۸٬۰۰۰`) |
| median | ۱۲ ریلِ آخر رو چشمی ببین و عددِ وسط رو بردار |
| views | بازدیدِ همین ریل |
| hook | خطِ اول، گفتاری یا روی صفحه، عینِ حرفشون با غلط‌های دستوری |
| on-screen | اولین کارتِ متن، اگه فرق داره |
| length | ثانیه |
| cta | آخرش چی خواستن |

median مهم‌ترینه. بدونش برگشتی به رتبه‌بندی با تعدادِ فالوور، که این اسکیل برای متوقف‌کردنش ساخته شده.

**وقتی اینستاگرام کافی نشون نمی‌ده:** همین گرامرِ هوک روی YouTube Shorts هم کار می‌کنه، جایی که بازدید و ترنسکریپت عمومیه و ورود لازم نیست. مجموعه‌ی دومِ مشروعیه و هوکِ گفتاری راحت‌تر به دست می‌آد:

```bash
# بازدیدِ شورت‌های یه کانال
python3 -m yt_dlp --flat-playlist --playlist-end 40 -J \
  "https://www.youtube.com/@HANDLE/shorts" > channel.json

# خطِ اولِ گفتاریِ یه شورت از زیرنویسِ خودکارش
python3 -m yt_dlp --skip-download --write-auto-subs --sub-langs "fa.*" \
  --sub-format json3 -o hook "https://www.youtube.com/watch?v=VIDEO_ID"
```

هر کلمه‌ی زیرنویس با زمانِ کمتر از ۳٫۰ ثانیه رو بردار. اون هوکه، همون‌طور که گفته شده، نه همون‌طور که نوشته شده. (زیرنویسِ خودکارِ فارسی غلط داره؛ قبل از استفاده بخونش.)

## قدمِ ۳: رتبه‌بندی

یه فایلِ جدا‌شده با تب با سطرِ عنوان پر کن و اسکریپت رو بزن:

```
account	followers	median	views	hook
@someone	48K	11K	412K	هیچ‌کس بهت نمی‌گه که سی تا ریلِ اولت قراره بسوزه
```

```bash
python3 swipe.py captured.tsv --out ~/.claude/instagram/swipe.md
```

ضریبِ outlier رو حساب می‌کنه، فرمول رو با همون ۲۹ فرمولی که `/ig-reel-fa` ازشون می‌نویسه اسم می‌ذاره، هر هوک رو با `hookscore.py` امتیاز می‌ده و چاپ می‌کنه چی یک‌سومِ بالا رو از یک‌سومِ پایین جدا می‌کنه. عددها هر شکلی پذیرفته می‌شن (`412000`، `۴۱۲٬۰۰۰`، `412k`، `۱٫۲ میلیون`).

## قدمِ ۴: بگو یعنی چی، با احتیاط

سه چیز گزارش بده و بیشتر نه:

1. **کدوم فرمول‌ها over-index می‌کنن** توی یک‌سومِ بالا، با تعداد. دو فرمول که هر کدوم چهار بار توی شش پیج ظاهر شدن یافته‌ست. یکی که دو بار اومده نه.
2. **چی ساختاراً بین یک‌سومِ بالا مشترکه** و توی پایین نیست: طولِ هوک، اینکه payoff بصریه، اینکه فریمِ اول حرکت داره، جای درخواست.
3. **سطرهای unclassified.** هر هوکی که طبقه‌بند نتونسته اسمش رو بذاره یا نویزه یا فرمولیه که هنوز توی `hooks.json` نیست. با دست بخونشون. این ارزشمندترین ستونِ خروجیه و دلیلِ چاپِ تعدادشه. (فرمول‌های فارسی مثل «میگن، ولی…» و «پدرم می‌گفت» از همین راه کشف شدن.)

بعد **حجمِ نمونه و میزانِ اطمینان** رو به زبانِ ساده بگو. چهل ریل از شش پیج ادعا رو پشتیبانی می‌کنه. دوازده تا نه، و گفتنش فرقِ تحقیق و فال‌گیریه. و بگو طبقه‌بندی با regex انجام شده: هوکی که تقریباً همون فرمول رو داره ولی با کلماتِ دیگه گفته شده، ممکنه unclassified بمونه.

## قدمِ ۵: تبدیلش کن به چیزی که بشه ضبط کرد

برای سه فرمولِ برتر **نسخه‌ی کاربر** رو بنویس: قصه‌ی خودش، عددِ خودش، توی شکلی که جواب می‌ده. هر کدوم رو با شماره‌ی فرمولِ از قبل انتخاب‌شده تحویلِ `/ig-reel-fa` بده.

هیچ‌وقت «یه ریل مثلِ این بساز» برنگردون. یه خطِ هوک برگردون که فردا بتونه بگه.

swipe file رو توی `~/.claude/instagram/swipe.md` بنویس. `/ig-reel-fa` و `/ig-plan-fa` هر دو می‌خوننش، و همین نکته‌ست: بعد از یه بار اجرا، بقیه‌ی بسته به‌جای پیش‌فرض‌ها از شواهدِ خودِ کاربر کار می‌کنه.

هیچ‌چیز توسط این اسکیل پست، فالو، لایک یا پیام نمی‌شه. فقط می‌خونه.
