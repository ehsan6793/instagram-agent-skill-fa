# ig-reel-fa

یه ایده‌ی خام رو تبدیل می‌کنه به ریلی که یه نفر تا آخرش ببینه.

دو ابزار توی همین پوشه هست و هر دو واقعاً اجرا می‌شن. ازشون استفاده کن. هوک رو چشمی قضاوت نکن و طول رو حدسی ندی.

```bash
python3 hookscore.py hooks.txt              # هوک‌های کاندید رو رتبه‌بندی کن
python3 hookscore.py --hook "یه خط"          # یه هوک رو امتیاز بده
python3 beats.py script.txt --target 30     # beat sheetِ زمان‌دار قبل از ضبط
python3 beats.py script.txt --calibrate "42 / 28"   # سرعتِ گفتارِ خودش رو حساب کن
```

روی ویندوز اگه فارسی توی ترمینال وارونه یا حرف‌حرف نشون داده شد: `--visual` (نیاز به `pip install arabic-reshaper python-bidi`). خروجیِ فایل و JSON همیشه درسته؛ این فقط نمایشه. اگه `python3` کار نکرد، `python` بزن.

## قبل از نوشتن

1. اگه `~/.claude/instagram/voice.md` هست بخونش. پروفایلِ صداشه: چطور جلوی دوربین حرف می‌زنه، چی هیچ‌وقت نمی‌گه، با کی حرف می‌زنه، **خطابش «تو»ست یا «شما»**، و لهجه/محاوره‌اش چقدره. اگه نیست، **سه تا ریلِ خودش** رو بخواه، بخون یا پیاده کن، صدا رو استنباط کن و فایل رو بنویس. اسکریپت به صدای اشتباه بی‌مصرفه چون باید با دهانش بگه.
2. `hooks.json` همین پوشه رو بخون. ۲۹ فرمول: ۲۶ تای اصلی (با همون شماره‌ها) + ۳ تای بومیِ فارسی (۲۷ «میگن، ولی…»، ۲۸ «جوابِ قیمت»، ۲۹ «پدرم می‌گفت»). هر کدوم قالب، مثالِ پرشده، نسخه‌ی روی صفحه، کاربرد و رایج‌ترین راهِ خراب‌کردنش رو داره.
3. اگه ایده نازکه، پُرش نکن. یه سوالِ دسته‌ای بپرس: چی شد، برای کی، چقدر خرج یا درآمد داشت. ریل یه چیزِ مشخصِ راست می‌خواد. قبل از نوشتن بگیرش.
4. اگه `~/.claude/instagram/swipe.md` هست بخونش. `/ig-viral-fa` اون رو می‌نویسه و شاهدِ خودِ کاربره درباره‌ی اینکه الان توی حوزه‌ی خودش کدوم فرمول‌ها جواب می‌دن. از پیش‌فرض‌های این فایل مهم‌تره.

## شکلِ ریل

ریل توی دو ثانیه‌ی اول تصمیم گرفته می‌شه و توی پنج ثانیه‌ی بعدی نگه داشته می‌شه.

```
0:00 - 0:02   HOOK        ادعا. خطِ گفتاری و خطِ روی صفحه جدا نوشته می‌شن. توی فریمِ اول حرکت، نه صورتِ ثابت.
0:02 - 0:07   THE STAKE   چرا این برای کسی که داره می‌بینه مهمه. یه خط.
0:07 - ...    THE BODY    هر بیت یه ایده، و فریم هر بیت عوض می‌شه.
۳ ثانیه‌ی آخر THE PAYOFF  چیزی که هوک قول داده بود رو تحویل بده، بعد یه درخواست.
خطِ آخر       THE LOOP    یه کلمه از هوک رو تکرار کن تا دیدنِ دوم تمیز بچسبه.
```

طول: ۱۵ تا ۴۵ ثانیه محدوده‌ی کاری‌ه. ریل تا ۳ دقیقه می‌شه و تقریباً هیچ‌کس نباید ازش استفاده کنه. زیر ۷ ثانیه فقط عددِ لوپ باد می‌کنه.

## حلقه‌ی کار

**۱. سه هوک انتخاب کن، نه یکی.** ایده رو از `hooks.json` رد کن، سه فرمولی که واقعاً می‌خوره رو بردار و برای هر کدوم خطِ گفتاری و خطِ روی صفحه بنویس. فرمول‌های متفاوت، نه سه بازنویسیِ یه چیز. اگه حوزه‌ی کاربر کسب‌وکارِ محلی یا فروشِ آنلاینه، حتماً #۲۸ رو هم بسنج؛ اگه قصه‌ست، #۲۹ و #۲۱.

**۲. امتیاز بده.** سه خطِ گفتاری رو توی یه فایل (هر خط یه هوک) بذار و `hookscore.py` رو بزن. رتبه‌بندی رو نشونش بده. اگه بهترین زیر ۵۰ بود هنوز هوک نداری و هیچ ویرایشی درستش نمی‌کنه.

**۳. اسکریپت رو روی هوکِ برنده بنویس.** فارسیِ **محاوره‌ای**: «می‌خوام» نه «می‌خواهم»، «رو» نه «را»، «اونجا» نه «آنجا»، «برا/واسه» اگه صدای خودشه. جمله‌ی کوتاه. هیچ جمله‌ای که لازم باشه تمرینش کنه. بزرگ‌ترین نشونه‌ی ماشینی‌بودنِ فارسی لحنِ کتابیه، پس بعدش حتماً `/ig-human-fa` رو رد کن.

**۴. زمان بگیر.** `beats.py script.txt --target {طول}` رو بزن. هر پرچم رو رفع کن: هوک بیشتر از ۳ ثانیه، هر بیت بیش از ۴ ثانیه، رشته‌ای از بیت‌ها بدون هیچ چیزِ مشخص، بدون لوپ. تا تمیز نشد تکرار کن. سرعتِ پیش‌فرض ۱۳۸ کلمه در دقیقه‌ست و **حدسه**، کالیبره نشده؛ اگه کاربر یه بار یه متن رو بلند و با تایمر خوند، `--calibrate "کلمه / ثانیه"` بده.

**۵. انسانی‌اش کن.** قبل از نشون‌دادن اسکریپت رو از `/ig-human-fa` رد کن (`--spoken` برای متنِ گفتاری). جمله‌ی کتابی همون لحظه‌ای که بلند گفته بشه لو می‌ره.

**۶. بلوکِ نهایی رو چاپ کن.** اسکریپت توی یه بلوکِ کد، متنِ روی صفحه یه فهرستِ جدا با زمان، و بعد:

```
REEL READY
hook:       #3 هیچ‌کس نمی‌گه، امتیاز ۸۷ STRONG
length:     28.4s across 9 beats at 138 wpm
on-screen:  6 cards
humanizer:  4 artefacts stripped, human score 81 PASS
caption:    بعدش /ig-caption-fa رو بزن

بنویس «آره» تا ثبتش کنم، یا بگو چی عوض بشه.
```

**۷. هیچ‌وقت منتشر نکن.** این اسکیل اسکریپت تولید می‌کنه. کاربر ضبط می‌کنه و می‌ذاره. با «آره» توی `~/.claude/instagram/log.md` اضافه کن: تاریخ، فرمولِ هوک و خطِ اول، تا `/ig-audit-fa` بعداً تاریخچه داشته باشه.

## متنِ روی صفحه یه اسکریپتِ جداست

هر بار جدا بنویس. قبل از شنیده‌شدن خونده می‌شه.

- **حداکثر شش کلمه در هر کارت.** از فاصله‌ی دست خونده می‌شه، توسط کسی که هنوز گوش نمی‌ده.
- **کارتِ هوک از فریمِ ۱ بالاست،** نه بعد از یه لحظه سکوت.
- **داخلِ safe zone نگه‌ش دار.** توی فریمِ ۱۰۸۰×۱۹۲۰ هیچ‌چیز بالای y=230 یا پایین y=1440 نباشه و ۲۳۰ پیکسلِ راست خالی بمونه. رابطِ کاربری روی همه‌چیزِ بیرونِ این کادر می‌شینه: کپشن، ستونِ دکمه‌ها، نوارِ صدا.
- **هوک رو جایی نذار که کپشن می‌شینه.** پایینِ فریمه و پوشیده می‌شه.
- **متنِ فارسیِ روی صفحه:** فونتی بذار که نیم‌فاصله رو درست نشون بده، راست‌چین باشه، و رقم‌ها یکدست (همه فارسی یا همه لاتین). قبل از ضبط یه بار توی خودِ ادیتور نگاهش کن: بعضی ادیتورها حروفِ فارسی رو جدا یا برعکس می‌چینن.
- **برای بدنه زیرنویس بسوزون.** بیشترِ آدم‌ها اول بی‌صدا می‌بینن.

## قاعده‌هایی که فرق می‌سازن

- **هر ریل یه ایده.** اگه اسکریپت دوتا داره، دو تا ریل داری. بگو.
- **عدد به جای صفت.** «۴ میلیون تومن» بهتر از «کلی». اگه کاربر عدد نداده، بپرس؛ دورِ سوراخ ننویس.
- **تومن یا تومان، میلیون یا میلیارد:** همونی که مخاطب توی گفتار می‌گه («چهار میلیون»، نه «۴٬۰۰۰٬۰۰۰ تومان»). روی صفحه می‌شه عدد نوشت.
- **مقدمه رو بپر.** نه سلام، نه «توی این ویدیو»، نه اسم، نه لوگو. ویدیو از جمله‌ای شروع می‌شه که معمولاً ثانیه‌ی ششم بهش می‌رسی.
- **هر بیت فریم عوض کن.** ۸ ثانیه شاتِ ثابت جاییه که آدم‌ها می‌رن و `beats.py` پرچمش می‌کنه.
- **آخر یه درخواست.** یه کلمه‌ی کلیدی کامنت کن، ذخیره کن، یا فالو. یکی. (کلمه‌ی کلیدی: یه کلمه‌ی ساده‌ی فارسی بدونِ فاصله‌ی قابل‌تایپ، مثل «قرارداد»؛ نه عبارتی که غلط تایپ بشه.)
- **خطاب رو ثابت نگه دار.** «تو» یا «شما»؛ نصفِ ریل «تو» و نصفِ دیگه «شما» نشه. پیش‌فرض از `voice.md`.
- **هیچ‌وقت جعل نکن.** نه عددِ ساختگی، نه مشتری، نه درآمد، نه نتیجه به اسمِ کاربر، حتی به‌عنوان جانگهدار. اگه عدد لازمه و معلوم نیست، `{{عدد تو}}` توی اسکریپت بذار و پرچمش کن. همین قانون برای جمله‌ی ضرب‌المثل و «بابام می‌گفت» (#۲۹): اگه واقعاً نگفته، نسبتش نده.
- **اسکریپت رو دور یه صدای ترندِ غیرقابل‌استفاده ننویس.** اگه ایده صدای خودِ کاربر می‌خواد، بگو.
- **آمار نیاور مگه منبع داشته باشی** (#۲۳). مثال‌های داخلِ `hooks.json` فقط شکلِ قالب رو نشون می‌دن، آمارِ واقعی نیستن.

## مثال

```
/ig-reel-fa زمانِ نوشتنِ پیشنهادِ قیمت رو با یه قالب از ۵ ساعت رسوندم به ۲۰ دقیقه
```

```
HOOKS  (scored)
  88  STRONG  #5  فشرده‌شدنِ زمان   «نوشتنِ پیشنهادِ قیمت قبلاً پنج ساعت وقتم رو می‌گرفت. الان بیست دقیقه.»
                                   روی صفحه: ۵ ساعت؟ حالا ۲۰ دقیقه
  72  STRONG  #1  اعتراف هزینه       «دو سال هر هفته چهار ساعتِ کارم فقط فرمت‌دادن بود.»
                                   روی صفحه: ۲ سالِ هدر
  54  OK      #9  بردارش            «این قالبِ پیشنهادِ قیمت رو بردار.»
                                   روی صفحه: کپی‌اش کن

ضبطِ #5: نسبتش باورپذیره، با یه نگاه روی صفحه خونده می‌شه و عدد مالِ خودته.
```

(نمره‌های بالا مثالِ شکلِ خروجی‌ان؛ برای هوک‌های واقعی خودِ `hookscore.py` رو اجرا کن.)

## صادق باش

`hookscore.py` پنج heuristic محلیه و پیش‌بینِ بازدید نیست. نسخه‌ی انگلیسیِ اصلی با داده‌ی واقعی سنجیده شده: خوب در جداکردنِ هوکِ واقعی از هوکِ عمداً بد، و تقریباً شانسی در جداکردنِ موفق از ناموفقِ یک خالق. **نسخه‌ی فارسی هنوز روی داده‌ی فارسی کالیبره نشده.** فقط برای گرفتنِ چیزهای واضح استفاده کن (سلام، مقدمه، هوکِ بدون چیزِ مشخص، هوکی که گفتنش پنج ثانیه طول می‌کشه). نمودارِ ماندگاری (retention) از این اسکریپت مهم‌تره.
