# ig-repurpose-fa

یه داراییِ بلندِ خوب چهار تا شش پست توش هست. بیشترِ آدم‌ها یکی برمی‌دارن و بقیه رو دور می‌ریزن.

## ورودی

یه ترنسکریپت، مقاله، خبرنامه، اسکریپت، خلاصه‌ی تماس، لایو. اگه کاربر URL داد و این نشست ابزارِ ترنسکریپت داره، استفاده کن؛ وگرنه بخواه paste کنه. قبل از هر استخراجی کلِ متن رو بخون.

اگه منبع ویدیویی‌ه که مالِ خودِ کاربره، فایلش رو هم بخواه. ریلِ ساخته‌شده روی فیلمِ خودش از ریلی که روی حرف‌های خودش دوباره خونده می‌شه بهتره.

**ترنسکریپتِ فارسی:** رونویسیِ خودکار (از یوتیوب یا هر ابزارِ تبدیلِ گفتار) توی فارسی غلط داره، مخصوصاً اسم‌ها، عدد‌ها و واژه‌های تخصصی و لاتین. قبل از استخراج، عدد و اسم‌ها رو با کاربر یا منبع تطبیق بده؛ عددِ غلط توی هوک یعنی ادعای جعلی به اسمِ کاربر.

## استخراج کن، خلاصه نکن

خلاصه‌ی یه ویدیو ریل نیست. هیچ‌کس خلاصه نمی‌خواد. دارایی رو بگرد و چیزهایی رو که مستقل می‌ایستن بکش بیرون:

| چی | چیه |
| --- | --- |
| **ادعاها** | هر جمله‌ای که می‌تونه یه بحث شروع کنه |
| **عددها** | هر رقم، هزینه، مدت، درصد |
| **قصه‌ها** | هر لحظه با یه آدم، یه صحنه و یه هزینه |
| **مکانیسم‌ها** | هر «روشی که واقعاً کار می‌کنه اینه که…» |
| **اشتباه‌ها** | هر اعترافِ چیزی که خراب شد |
| **جمله‌ها** | هر جمله‌ای که همون‌طور که هست قابل‌نقله (ضرب‌المثل‌ها و «بابام می‌گفت»ها هم، با فرمول‌های #۲۷ و #۲۹) |

قبل از نوشتن هر چیزی، چیزهایی که پیدا کردی رو با تعداد فهرست کن. اگه دارایی کمتر از چهار تا ازشون می‌ده، نازکه و چهار پستِ فشرده‌شده ازش هم نازک می‌شه. بگو.

## بعد فرمت رو برای هر کدوم انتخاب کن

همه‌چیز ریل نیست.

- **ادعا، اشتباه، قصه** ← ریل. صدا و صورت می‌خوان.
- **مکانیسم، فهرستِ شماره‌دار** ← کاروسل. باید دوباره خونده بشن.
- **یه جمله‌ی قابل‌نقل** ← فریمِ استوری، نه پست.

## بعد هفته رو بساز

هر استخراج یه پست می‌شه و هر پست کاملاً مستقل می‌ایسته. بیننده منبع رو ندیده و هیچ‌وقت نمی‌بینه. هیچ‌وقت ننویس «همون‌طور که توی آخرین ویدیوم گفتم». پست خودِ چیزه.

به هر کدوم یه فرمولِ هوک از `ig-reel-fa/hooks.json` بده و متنوع کن. پنج پست از یه منبع با یه شکلِ هوک مثلِ کارخونه‌ی محتوا خونده می‌شه، چون هست.

اگه منبع ویدیوی خودِ کاربره، **از فیلمِ واقعی استفاده کن.** کلیپی که توش گفته، با واکنشِ واقعی، همیشه از ضبطِ دوباره بهتره. روی جمله ببُر، نه روی نفس.

ترتیبِ هفته: قوی‌ترین ادعا اول، قصه وسطِ هفته، مکانیسم آخر، وقتی کسایی که پست‌های قبلی رو دوست داشتن منتظرشن.

## خروجی

```
SOURCE: «چرا تماسِ کشفِ نیاز رو حذف کردیم» (پادکستِ ۴۲ دقیقه‌ای، ۸٬۹۰۰ کلمه)

FOUND  ۵ ادعا، ۹ عدد، ۳ قصه، ۴ مکانیسم، ۲ اشتباه، ۷ جمله‌ی قابل‌نقل

WEEK
یکشنبه   ریل      #2  دستور منفی       دیگه تماسِ کشفِ نیاز نذار
                                        کلیپِ دقیقه‌ی ۱۴:۲۰، آخرش می‌خنده
سه‌شنبه   کاروسل   کپشنِ کارِ B         فرمِ ۴ سوالی که جای تماس رو گرفت
پنجشنبه   ریل      #21 شروع وسطِ جمله   «...و نُه روز بعد پولش رو پس خواست»
جمعه     ریل      #5  فشرده‌شدنِ زمان   شش ساعت در هفته برگشت، یه لینکِ حذف‌شده

بگو «یکشنبه رو بنویس» تا پیش‌نویسش کنم.
```

بعد درخواستی پیش‌نویس کن، یکی‌یکی، هر کدوم از `/ig-reel-fa` و `/ig-human-fa`. چهار اسکریپتِ تمام‌شده رو یه‌جا نریز. همه‌شون شبیهِ هم صدا می‌دن و کاربر هیچ‌کدوم رو ضبط نمی‌کنه.
