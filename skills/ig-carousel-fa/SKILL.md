# ig-carousel-fa

کاروسل پربازدیدترین (از نظر زمانِ ماندن) فرمتِ گریده، چون اسلاید‌کردن یه تعامله و اسکرول نیست. شانسِ دوم هم داره: اینستاگرام می‌تونه کاروسل رو دوباره، این بار از یه اسلایدِ بعدی، به کسی که بارِ اول تعامل نکرده نشون بده، پس **اسلایدِ دو** هم باید خودش بایسته.

فرمت یه ایده‌ی شکسته به قدم‌ها رو پاداش می‌ده. کپشنِ تکه‌تکه‌شده رو تنبیه می‌کنه.

## کی به‌جای ریل

وقتی ایده **ترتیب داره و باید دوباره خونده بشه**: قدم‌ها، یه چارچوبِ چندبخشی، قبل‌وبعد، فهرستی که ارزشِ اسکرین‌شات داره. ریل وقتی که ایده حرکت داره، صورت، یا payoffی که باید دید اتفاق می‌افته.

اگه ایده یه ادعاست، هیچ‌کدوم نیست. بده به `/ig-reel-fa` و بگو.

## ساختار

۶ تا ۱۰ اسلاید. سقف ۲۰ تاست و ۲۰ تقریباً همیشه کتابیه که کسی تمومش نمی‌کنه. زیر ۵ تا اسلاید هیچ‌وقت شروع نمی‌شه.

```
1         COVER     هوک. شش کلمه یا کمتر، با اندازه‌ای که توی گرید در سایزِ بندانگشتی خونده بشه.
                    زیرش یه خط قول.
2         THE STAKE چرا مهمه، یه جمله. این اسلاید یه کاورِ دومه، پس نمی‌تونه مقدمه باشه.
3 تا N    هر اسلاید یه ایده. تیتر ۳ تا ۷ کلمه، حداکثر ۲۵ کلمه زیرش. اگه اسلاید پاراگراف می‌خواد، دو اسلاید.
N+1       RECAP     کلِ چیز به‌شکلِ فهرست. اسلایدِ اسکرین‌شات.
آخر       CTA       یه کار. ذخیره، کامنتِ یه کلمه، یا فالو. یکی.
```

## قاعده‌های متنِ اسلاید

- **کاور ۸۰٪ نتیجه‌ست.** شش کلمه. بزرگ. هیچ‌چیزِ بقیه‌ی دسته کاوری رو که کسی اسلایدش نمی‌کنه نجات نمی‌ده.
- **برای برشِ گرید طراحی کن.** گرید به یه مستطیلِ عمودی برش می‌ده و نسبتِ دقیق چند بار عوض شده. ۱۰۸۰×۱۳۵۰ بساز و متنِ کاور رو خیلی وسط نگه دار، دور از ۱۲۰ پیکسلِ لبه‌ها؛ برش دیگه مهم نیست.
- **اسلایدها رو شماره بزن** (۳/۸). وقتی آدم‌ها پایان رو می‌بینن تکمیل بیشتر می‌شه.
- **هیچ اسلایدی پاراگراف نیست.** اگه توی ۲۵ کلمه جا نمی‌شه، بشکنش.
- **اسلایدِ recap همونیه که آدم‌ها اسکرین‌شات می‌گیرن و می‌فرستن.** ارسال قوی‌ترین سیگنالیه که می‌شه گرفت. مستقل و بدونِ بافت قابل‌خوندن باشه.
- **هندل روی هر اسلاید،** کوچیک، گوشه‌ی پایین. اسکرین‌شات‌ها بدونِ تو سفر می‌کنن.
- **متنِ جایگزین (alt) دست‌کم برای کاور.** صفحه‌خوان و اینستاگرام می‌خونن.

### فارسی روی اسلاید

- **جهتِ اسلاید رو روی گوشیِ خودت تست کن.** توی رابطِ راست‌به‌چپ ممکنه حس و جهتِ اسلایدکردن فرق کنه. مطمئن نیستی؟ شماره‌ی اسلاید و نشانه‌ی «ادامه ←» بذار تا مخاطب گیج نشه.
- **راست‌چین،** با فونتی که نیم‌فاصله و حروفِ فارسی رو درست می‌چینه (مثل وزیرمتن، ایران‌سنس، یکان‌بخ، IBM Plex Sans Arabic). فونتِ اشتباه حرف‌ها رو جدا یا برعکس نشون می‌ده.
- **رقم‌ها یکدست:** یا همه فارسی یا همه لاتین توی کل کاروسل.
- **عنوانِ کوتاه** (فارسی دیرتر خونده می‌شه): ۶ کلمه‌ی کاور واقعاً شش تا باشه، نه هشت.
- **اگه کلمه‌ی لاتین قاطی می‌شه** (برند، ابزار)، جهتِ علامت‌ها (نقطه، پرانتز) رو توی رندر بررسی کن؛ قاطیِ فارسی-لاتین جاییه که bidi خراب می‌شه.

## ساختنِ فایل‌ها

اینستاگرام ۱۰۸۰×۱۳۵۰ (۴:۵)، JPEG یا PNG، تا ۲۰ آیتم می‌خواد. با HTML بساز و هر اسلاید رو چاپ کن:

```bash
# هر اسلاید یه <section>، ۱۰۸۰×۱۳۵۰، page-break-after: always
# بعد Chrome headless --print-to-pdf، یا هر HTML-to-image که از قبل داری
```

HTML رو با `<html lang="fa" dir="rtl">`، `width:1080px; height:1350px`، یه رنگِ تأکید، و فونتی با نیم‌فاصله‌ی درست بنویس؛ و اندازه‌ی نوشته کمتر از ۳۲px نباشه، چون روی گوشی با یک‌سومِ اندازه‌ی واقعی خونده می‌شه. اگه پروژه اسکیلِ برند یا design system داره، ازش استفاده کن و پالت اختراع نکن. فونت‌ها رو **به‌صورت فایل داخلِ پروژه** بیار (نه CDN) تا رندر روی هر سیستم یکی باشه.

## خروجی

اول متنِ اسلاید-به-اسلاید، به‌شکل فهرستِ شماره‌دار که کاربر ده ثانیه‌ای بخونه و قبل از رندر ویرایش کنه. بعد **کپشن**، که برای کاروسل کارِ B توی `/ig-caption-fa` هست: کپشن اینجا کار می‌کنه، چون کاور شش کلمه‌اش رو خرج کرده.

هر دو رو از `/ig-human-fa` رد کن. فایل‌ها رو فقط بعد از تأییدِ متن بساز.

```
CAROUSEL  |  8 slides

1  COVER   بندِ ۱۸ میلیونی
           یه خطی که الان توی هر قرارداد می‌ذارم.
2  STAKE   کار رو تأیید کردم. نُه روز بعد پولش رو پس خواستن.
3          چی می‌گه
           پرداخت موقعِ تحویل، نه موقعِ تأیید.
...
7  RECAP   هر چهار خط، به ترتیب.
8  CTA     کامنت کن «قرارداد» تا متنِ کاملش رو بفرستم.

Caption: کارِ B، هوک توی خطِ ۱، یه درخواست، ۳ هشتگ.
```

هیچ‌چیز آپلود نمی‌شه. کاربر منتشر می‌کنه.
