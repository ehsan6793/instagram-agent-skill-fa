# اسکیلِ اینستاگرام، نسخه‌ی فارسی
**Instagram Agent Skill (Persian / Farsi)**

سیزده اسکیلِ Claude برای مدیریتِ یه پیجِ اینستاگرامِ فارسی. رایگان، MIT، بدونِ ثبت‌نام، بدونِ API key، چیزی برای وصل‌کردن نیست.

این یه **اقتباسِ فارسی** از [`Jakeschincariol/instagram-agent-skill`](https://github.com/Jakeschincariol/instagram-agent-skill) است (جزئیات: [NOTICE.md](NOTICE.md)). ترجمه‌ی خطبه‌خط نیست؛ برای فارسی دوباره نوشته شده، چون اسکیلِ انگلیسی روی فارسی خراب می‌شه: نیم‌فاصله رو پاک می‌کنه، حرفِ بزرگ و `\b` فرض می‌کنه، و لحنِ کتابیِ فارسی رو که بزرگ‌ترین نشونه‌ی ماشینیه نمی‌بینه.

*A Persian adaptation of Jake Schincariol's 13-skill Instagram pack for Claude. Not a translation: rewritten for Persian text (ZWNJ-safe cleaning, colloquial register, Persian hook formulas, Shamsi calendar, Tehran time), with six local tools that run offline. MIT.*

یکی‌شون ریل‌هات رو از روی ۲۹ فرمولِ هوک می‌نویسه و قبل از اینکه یه تیک رو هدر بدی هوک رو امتیاز می‌ده. یکی می‌ره و می‌گرده ریل‌هایی که واقعاً توی حوزه‌ی تو جواب می‌دن رو پیدا می‌کنه و بر اساس اینکه هر کدوم چقدر از میانگینِ پیجِ خودش جلو زده رتبه‌بندی می‌کنه. یکی کپشن می‌نویسه و دقیقاً نشون می‌ده فید قبل از «... بیشتر» چی نشون می‌ده. یکی پروفایلت رو از ۱۰۰ نمره می‌ده. یکی هفته رو برنامه‌ریزی می‌کنه.

و یکی humanizer است، که دلیلِ قابل‌استفاده‌بودنِ بقیه‌ست: کلیشه‌ها، لحنِ کتابی و کاراکترهای نامرئی رو از پیش‌نویس درمیاره و بعد با یه پنلِ شش‌تاییِ چک امتیازش می‌ده، **بدون اینکه نیم‌فاصله‌ی فارسی رو خراب کنه**.

**تا وقتی تو نگی آره هیچ‌چیز منتشر نمی‌شه.** این اسکیل‌ها می‌نویسن. تو پست می‌کنی.

## نصب

### راهِ ساده: به Claude بگو

```
https://github.com/ehsan6793/instagram-agent-skill-fa

این اسکیل رو نصب کن، بعد تأیید کن که /ig-reel-fa کار می‌کنه.
```

### دستی، توی Claude Code

**ویندوز (PowerShell):**

```powershell
git clone https://github.com/ehsan6793/instagram-agent-skill-fa.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills", "$HOME\.claude\instagram" | Out-Null
Copy-Item -Recurse -Force instagram-agent-skill-fa\skills\ig-* "$HOME\.claude\skills\"
Copy-Item instagram-agent-skill-fa\templates\voice.md "$HOME\.claude\instagram\voice.md"
```

**مک / لینوکس:**

```bash
git clone https://github.com/ehsan6793/instagram-agent-skill-fa.git
mkdir -p ~/.claude/skills ~/.claude/instagram
cp -r instagram-agent-skill-fa/skills/ig-* ~/.claude/skills/
cp instagram-agent-skill-fa/templates/voice.md ~/.claude/instagram/voice.md
```

### یا به‌صورتِ پلاگین

```
/plugin marketplace add ehsan6793/instagram-agent-skill-fa
/plugin install instagram-agent-fa
```

پوشه‌ها `ig-*-fa` اسم دارن، پس **کنارِ نسخه‌ی انگلیسی** هم نصب می‌شن و تداخل ندارن. به‌جای نصبِ سراسری می‌تونی همین پوشه‌ها رو توی `.claude/skills/` همون پروژه بذاری. بدونِ Claude Code هم: `SKILL.md` هر اسکیل رو بالای یه گفتگو paste کن تا مثلِ یه حالت کار کنه؛ شش ابزارِ پایتون (که بخشِ بزرگی از ارزشِ `/ig-reel-fa` و `/ig-human-fa` هستن) رو از دست می‌دی.

### پایتون

ابزارها فقط به **Python ۳٫۹ به بالا** نیاز دارن و هیچ پکیجِ اضافه‌ای نمی‌خوان. روی ویندوز دستور `python` است (نه `python3`)؛ اگه `python3` خطا داد `python` بزن. اگه فارسیِ ترمینال وارونه یا حرف‌حرف نشون داده شد (ترمینال‌هایی که راست‌به‌چپ بلد نیستن)، اختیاری:

```
pip install arabic-reshaper python-bidi
python hookscore.py --visual ...
```

`--visual` فقط **نمایشِ ترمینال** رو درست می‌کنه. فایل‌ها و خروجیِ `--json` همیشه متنِ درستِ یونیکدن.

### صدای خودت

بعد ده دقیقه روی `templates/voice.md` وقت بذار. `~/.claude/instagram/voice.md` (ویندوز: `%USERPROFILE%\.claude\instagram\voice.md`) رو پر کن، یا سه تا ریل یا کپشنِ خودت رو بده به Claude و بگو «از اینا voice.md من رو بنویس». هر اسکیل می‌خونتش و این‌جا از هرجای دیگه مهم‌تره، چون باید کلمه‌ها رو بلند بگی. خطابِ «تو/شما»، لهجه و رقم‌ها هم همین‌جا ثابت می‌شن.

شش‌تاش ابزارِ پایتونِ واقعی دارن که واقعاً اجرا می‌شن:

```bash
python hookscore.py hooks.txt                  # رتبه‌بندیِ هوک‌ها        (ig-reel-fa)
python beats.py script.txt --target 30         # beat sheetِ زمان‌دار       (ig-reel-fa)
python humanize.py draft.txt --spoken --report # تمیز + محاوره‌ای          (ig-human-fa)
python detect.py draft.txt                     # پنلِ شش‌تایی              (ig-human-fa)
python caption.py caption.txt --keywords "..." # لینتِ کپشن               (ig-caption-fa)
python swipe.py captured.tsv                   # رتبه‌بندیِ ریل‌های جمع‌شده  (ig-viral-fa)
```

## چی برای فارسی فرق می‌کنه

- **نیم‌فاصله زنده می‌مونه.** اسکیلِ انگلیسی هر U+200C رو پاک می‌کنه («می‌روم» می‌شه «میروم»). اینجا نیم‌فاصله‌ی بینِ دو حرف، ZWJ توی ایموجی، و LRM/RLM روی خطِ فارسی-لاتین نگه داشته می‌شن؛ فقط نیم‌فاصله‌ی تکراری یا ولگرد و کاراکترهای واقعاً نامرئی می‌رن.
- **لحن (REGISTER).** بزرگ‌ترین نشونه‌ی فارسیِ ماشینی یه واژه نیست، لحنه: «می‌خواهم/را/اکنون/جهت/لذا» جایی که آدم جلوی دوربین می‌گه «می‌خوام/رو/الان/برای/برای همین». `detect.py` اندازه‌ش می‌گیره و `humanize.py --spoken` تقریبی محاوره‌ای‌ش می‌کنه.
- **«مشخص‌بودن» بدونِ حرفِ بزرگ.** فارسی capital نداره؛ مشخص‌بودن از عدد (فارسی و لاتین، «۱۸ میلیون»)، @هندل، «نقل‌قول»، برندهای لاتین و فهرستِ اسم‌ها و پول‌واژه‌ها حساب می‌شه.
- **املا و رقم یکدسته.** ي/ك عربی ← ی/ک، رقمِ عربی ← فارسی؛ اختیاری: `--persian-digits`، `--persian-punct` (؟ ، ؛).
- **سه فرمولِ هوکِ بومی** علاوه بر ۲۶ تای اصلی: #۲۷ «میگن، ولی…» (ضرب‌المثل و وارونه‌اش)، #۲۸ «جوابِ قیمت» (فرهنگِ «قیمت؟» توی دایرکت)، #۲۹ «پدرم می‌گفت…».
- **بازارِ ایرانی.** تقویمِ شمسی و هفته‌ی شنبه‌محور، ساعتِ تهران، تومن/میلیون، لینکِ بیو که بدون فیلترشکن باز بشه، خطابِ تو/شما، دایرکتِ فارسی که «سلام» توش نُرمه (برعکسِ هوکِ ریل).
- **ویندوز.** خروجیِ UTF-8 اجباری، خوانش با BOM، `python -I`، و `--visual` برای ترمینال‌های بدونِ راست‌به‌چپ.

## صادق باش (محدودیت‌ها)

- **امتیازها کالیبره نیستن.** `hookscore.py` و `detect.py` heuristic‌اند و پیش‌بین نیستن. نسخه‌ی انگلیسیِ اصلی با ۷۴ هوکِ واقعی سنجیده شده و گزارش می‌ده در جداکردنِ هوکِ واقعی از هوکِ عمداً بد خوب است (AUC حدودِ ۰٫۸۳) ولی در جداکردنِ موفق از ناموفقِ یک سازنده تقریباً شانسی (حدودِ ۰٫۵۶). **نسخه‌ی فارسی روی داده‌ی فارسی کالیبره نشده.** فقط برای گرفتنِ چیزهای واضح خوبه (سلام، مقدمه، هوکِ بدون چیزِ مشخص، لحنِ کتابی). نمودارِ ماندگاری (retention) مهم‌تره.
- **`detect.py` ابزارهای دیگه نیست.** GPTZero، Originality و امثالشون نیست، به هیچ‌کدوم وصل نیست و حکمشون رو تضمین نمی‌کنه (و فارسی رو معمولاً ضعیف‌تر از انگلیسی می‌فهمن). هیچ چیزی آپلود نمی‌شه.
- **سرعتِ گفتار حدسه.** پیش‌فرضِ `beats.py` ۱۳۸ کلمه در دقیقه است. یه بار یه متن رو با تایمر بخون و `--calibrate "کلمه / ثانیه"` بده.
- **`--spoken` تقریبیه** و لهجه‌های محلی رو نمی‌شناسه؛ نتیجه رو بخون.
- **طبقه‌بندیِ هوک با regex انجام می‌شه.** هوکی که همون فرمول رو با کلماتِ دیگه گفته ممکنه `unclassified` بمونه؛ این عمداً دیده می‌شه تا فرمولِ جدید کشف بشه.
- **«۱۲۵ نویسه» تقریبیه.** عددِ برشِ «... بیشتر» با دستگاه و فونت عوض می‌شه (`--truncate` برای تست).
- **سقفِ ۵ هشتگ** واقعیه: اینستاگرام ۱۸ دسامبر ۲۰۲۵ اعلامش کرد و اعمالش تدریجی بوده.

## تست

```bash
python -m unittest discover -s tests -v
python tools/sync_fatext.py --check     # چهار کپیِ fatext.py یکی باشن
```

هر ابزار توی پوشه‌ی اسکیلِ خودش مستقله، پس `fatext.py` (لایه‌ی مشترکِ متنِ فارسی) توی چهار پوشه کپی شده. **فقط `skills/ig-reel-fa/fatext.py` رو ویرایش کن** و بعد `python tools/sync_fatext.py` رو بزن.
